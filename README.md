# 📝 To-Do App

A simple **To-Do REST API** built with **FastAPI** and **SQLAlchemy**.

This project is being developed alongside my journey of learning FastAPI, backend development, and working with databases using SQLAlchemy.

## 🚀 Tech Stack

- 🐍 Python
- ⚡ FastAPI
- 🗄️ SQLAlchemy
- 📦 Pydantic
- 🛢️ SQLite
- 🧪 Uvicorn

## 🎯 Project Goal

The main goal of this project is to learn and practice:

- FastAPI fundamentals
- Creating REST APIs
- API routing and endpoints
- Request and response handling
- Pydantic models
- SQLAlchemy ORM
- Database operations
- CRUD operations
- Connecting FastAPI with a database
- Project structure and backend development
